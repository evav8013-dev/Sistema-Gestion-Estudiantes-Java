# Sistema de Gestión de Estudiantes (Java)

Proyecto académico para practicar Programación Orientada a Objetos.

## Requisitos
- JDK 17 o superior (también puede funcionar con versiones recientes anteriores).
- IntelliJ IDEA, Eclipse, NetBeans o VS Code con Java.

## Archivos
- `src/Estudiante.java`: clase con atributos, constructor y métodos.
- `src/Main.java`: punto de entrada; crea objetos y prueba los métodos.

## Ejecutar desde terminal
Desde la carpeta del proyecto:

```bash
javac src/Estudiante.java src/Main.java
java -cp src Main
```

## Conceptos aplicados
- Clase: `Estudiante`.
- Atributos: `nombre`, `matricula`, `calificacion`.
- Constructor: inicializa los atributos del objeto.
- Objetos: `estudiante1` y `estudiante2`.
- Métodos: getters, `setCalificacion`, `aprobo` y `mostrarInformacion`.
- Encapsulamiento: atributos privados y acceso mediante métodos.

## Regla de aprobación
Una calificación de 70 a 100 se considera aprobatoria. La calificación debe estar entre 0 y 100.

# Sistema-Gestion-Estudiantes-Java
El presente proyecto consiste en desarrollar una aplicación sencilla en Java para gestionar información básica de estudiantes. El ejercicio permite poner en práctica los fundamentos de la Programación Orientada a Objetos (POO), mediante la definición de una clase, sus atributos, un constructor, la creación de objetos y la ejecución de métodos
